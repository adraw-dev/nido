# Nido

Organización del hogar en pareja: tareas compartidas, hábitos, finanzas y vehículos, en una sola app Android.

**Stack:** Expo SDK 58 · React Native · Expo Router · Supabase (Auth, Postgres con RLS, Realtime, Storage).
